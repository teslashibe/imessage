# Support

Use GitHub issues for reproducible package bugs and focused feature requests.
Include the package version, Go version, exact imsg version, operating system,
expected behavior, and sanitized reproduction steps.

Questions about installing imsg, macOS permissions, Messages configuration, or
the private IMCore bridge belong with the
[imsg project](https://github.com/openclaw/imsg). This package cannot provide
support for weakening SIP or other macOS protections.

Never post message contents, participant identifiers, credentials, database
paths, or raw RPC payloads. Report security issues according to
[SECURITY.md](SECURITY.md).
